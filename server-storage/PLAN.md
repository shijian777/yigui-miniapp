# 独立存储服务实施计划

目标：为丹姐小程序准备可以在指定 Google VM 安装的独立持久化服务，不改其他业务。

设计：Python 3 标准库 HTTP 服务 + 专属 SQLite。监听 127.0.0.1:18473，Bearer 凭据保存在专用配置目录。数据采用带版本号的完整账目快照；条件写入防止多个设备互相覆盖，请求 ID 保证网络重试幂等。此阶段只安装存储基础服务，小程序客户端接入/HTTPS域名/真实数据迁移单独验证后启用。

文件与步骤：

- [x] test_storage.py：验证认证、版本冲突、重复请求、并发写入、重启持久化、数据库失败回滚及备份恢复，共 17 项。
- [x] storage_server.py：实现 /healthz、GET/PUT /v1/state、GET /v1/history、GET /v1/history/{revision}，限制请求容量和并发数。
- [x] install.sh + installer.py：检查机器、端口、独立路径和服务名冲突；不升级系统、不修改防火墙或 Caddy；创建专属低权限账号和 systemd 单元。
- [x] 将安装前自检复用为 test_storage.py：使用独立临时数据库运行真实 HTTP 读写及重新启动验证，不污染正式业务库。
- [x] README.md：准确列出安装方式、数据位置、回退停止方法、尚未完成的客户端接入。
- [x] 独立代码审查：备份失败清理问题已修复，审查确认无待处理发现。
- [x] 最终 17 项测试通过，tar.gz 内 9 个条目逐字节核对，写入 SHA256，安装包已复制到桌面；待用户通过已有浏览器 SSH 上传执行。

上线仍需用户已打开的 SSH 通道执行，自动浏览器工具当前不可用。18473 仅由截图确认当前无 TCP 监听，安装时再次绑定检查；既有配置可能使用该端口时应停止核实。
