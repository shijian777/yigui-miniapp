# 丹姐女装童装小程序

服装店进销存、销售开单、欠款、客户对账及小票打印小程序的修复版源码。

**当前使用本地数据模式。** 设备之间尚未自动同步；配套 Google 服务器存储服务已单独安装，但 HTTPS、域名和小程序客户端接入尚未完成。上传本仓库不会部署或迁移账本。

## 打开小程序

1. 克隆或下载本仓库。
2. 在微信开发者工具中导入 `danjie-connected-miniapp` 目录。
3. 使用有相应 AppID 开发权限的微信登录，点击编译，再点击预览生成手机二维码。

工程目录名称中的 connected 是接入准备阶段的名称；请保持 `app.js` 中的 `useLocal: true`。`cloudfunctions` 保留原版 CloudBase 源码，尚未适配本轮新增的原子商品保存接口，不能直接切换使用。

首次成功写入会把旧本地集合保存为新版账本快照，旧集合保留。请先保留有效备份，之后固定使用修复版，避免旧版继续读取旧数据。

## 目录

| 路径 | 内容 |
| --- | --- |
| `danjie-connected-miniapp/` | 当前小程序源码、图片资源及原有 CloudBase 云函数 |
| `client-tests/` | 业务、页面、库存事务、备份恢复等回归测试 |
| `server-storage/` | Python/SQLite 存储服务及安装器、服务端测试 |
| `verify-fixed-miniapp.cjs` | JavaScript/JSON/页面绑定检查及客户端测试入口 |

原包中的 H5 演示、截图、预览二维码及本机私有配置不属于当前小程序发布源码，未纳入仓库。实际账本和运行时服务凭据不随源码保存。

## 主要修复

- 编辑颜色、尺码保留 SKU 库存和价格；库存变化后拒绝过期表单覆盖。
- 商品与期初流水、销售、进货、退货分别作为完整业务事务保存，失败时整次撤销。
- 销售、进货和补收支持请求重试去重；合法零成本不再错误回退默认成本。
- 修复欠款漏计、客户余额不归零、退货重复扣减对账金额、日期更新损坏及日期筛选。
- 修复流水游标、切换筛选异步覆盖、客户选择器和付款状态重置。
- 修复超过 200 名欠款客户总额、超过 500 条 SKU 迁移和超过 1,000 条全量读取。
- 完整备份、恢复、恢复前副本与账本原子提交；拒绝会破坏已有商品库存一致性的交易合并。
- 大账本分块保存，提交索引失败仍可读取上一份账本，并回收中断遗留分块。

已经被旧版损坏的历史库存或日期需要依据有效备份和单据核对，修复代码不会猜测原值。

## 验证

客户端验证使用 Node.js 24，测试只使用内置模块：

```sh
node verify-fixed-miniapp.cjs
```

服务端使用 Python 3.10+ 标准库，通过真实 HTTP 与临时 SQLite 数据库验证：

```sh
python server-storage/test_storage.py
```

上传前验证：客户端 93 项、服务端 17 项测试通过。客户端测试执行真实业务代码，微信存储、页面和文件接口采用隔离模拟。修复版已在微信开发者工具显示首页并成功生成预览二维码；手机完整流程、相机扫码和蓝牙打印机仍需实机验收。

存储服务默认仅监听 `127.0.0.1:18473`。安装器会核对指定主机和已有服务，请先阅读 [服务端说明](server-storage/README.md)，不要把服务器安装与小程序接入视为同一步。
