# 衣柜小程序

衣柜是一款面向服装店的微信进销存与记账小程序，支持商品、颜色尺码库存、采购入库、销售开单、折扣欠款、客户供应商、整单退货、对账和小票打印。

## 文件与功能

| 目录/文件 | 功能 |
| --- | --- |
| `yigui-miniapp/` | 小程序源码、图片及历史 CloudBase 云函数 |
| `yigui-miniapp/pages/` | 商品、进货、销售、订单、客户、欠款、统计、小票和设置页面 |
| `yigui-miniapp/utils/` | 本地数据库、原子账本、库存金额计算和备份恢复 |
| `client-tests/` | 业务、页面、库存事务、备份恢复回归测试 |
| `server-storage/` | Python/SQLite 存储服务、安装器、定时备份及服务测试 |
| `verify-fixed-miniapp.cjs` | JavaScript、JSON、页面绑定及客户端测试入口 |

## 打开与验证

下载仓库后，在微信开发者工具导入 `yigui-miniapp` 目录，保留原 AppID，使用有开发权限的微信登录并编译。

客户端检查：`node verify-fixed-miniapp.cjs`（Node.js 24）。服务端检查：`python server-storage/test_storage.py`（Python 3.10+）。历史验证记录为客户端 93 项、服务端 17 项通过；本次名称整理不代表重新完成手机或服务器联调。

## 当前使用边界

当前 `app.js` 使用 `useLocal: true`，数据保存在当前设备，设备之间尚未自动同步。独立存储服务的 HTTPS、域名和客户端接入仍需完成。历史云函数尚未适配新增的原子商品保存接口，不能直接切换使用。

支持完整备份、合并、覆盖恢复和恢复前副本。改名沿用原账本存储键和服务器部署路径，以保持已有数据兼容；用户填写的店铺名称继续按设置显示。

手机完整流程、扫码、蓝牙打印仍需实机验收。服务默认监听 `127.0.0.1:18473`，部署前阅读 [服务端说明](server-storage/README.md)。
